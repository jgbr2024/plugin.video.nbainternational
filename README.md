# NBA  League Pass Kodi Plugin

- Live NBA Games, NBA TV, Archived Games and Classic Games
- Requires an Active NBA League Pass Subscription

## Install tips
 - You can install the most up-to-date version of this plugin by downloading the zip file from the 'Dev' Branch on this page
 - To get automatic updates you can download and install my repository from https://github.com/chamchenko/repository.chamchenko

## What Works
 - Live NBA TV
 - Archived games (with optional score hiding in settings)
 - Classic games by team (from the NBA TV page)
